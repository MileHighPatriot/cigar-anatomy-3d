# Cigar Anatomy 3D

A 3D cigar you can spin in any direction, pull apart layer by layer, and rebuild in different sizes, shapes, wrappers, and countries.

- Open it through a web server (it uses JavaScript modules): `python3 -m http.server` in this folder, then visit http://localhost:8000.
- Facts come from the Cigar Lounge Mastery study guide.
- Leaf textures are generated by `tools/make_textures.py` (Python, numpy, Pillow) into `assets/tex/`.
- Studio lighting: "Studio Small 09" HDRI from Poly Haven (CC0), `assets/studio.hdr`.
- three.js 0.187 is vendored in `vendor/` so the page works offline.
